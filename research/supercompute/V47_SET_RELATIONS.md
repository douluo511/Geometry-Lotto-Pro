# SSQ + DLT V4.7: 属于、不属于、包含、不包含（数学事件验收）

每个彩种必须在自己的完整号码区域内分别计算，不能混用前区和后区：

- 双色球红球（front）01–33，每期开6个；蓝球（back）01–16，每期开1个。
- 大乐透前区（front）01–35，每期开5个；后区（back）01–12，每期开2个。

设某区域开奖号码集合为 R，选中单球 x，正向集合 A，负向集合 E。

| 判断 | 数学式 | 真正含义 | 何时判成功 |
| ---- | ----- | ------- | ---------- |
| 单球属于 | x ∈ R | 该号码开出 | 成员 |
| 单球不属于 | x ∉ R | 该号码未开出 | 非成员 |
| M+ 包含于 | A ⊆ R | A 中**所有**号码都开出 | 所有成员成功 |
| 数学“不包含于” | E ⊈ R | E 中**至少一个**号码没开出 | 只是诊断，禁止计 M- 成功 |
| M- 严格完全排除 | E ∩ R = ∅ | E 中**所有**号码均未开出 | **零个排除号码开出** |

举例：R={04,13,14,22,24,30}，E={08,30}；E ⊈ R 为 TRUE，但 E∩R=∅ 为 FALSE。即反向 M- FAIL。不能因为出现部分排除正确而给予成功。

零个约束：在四区域动态搜索的某个区域 A=∅ 或 E=∅，对应集合运算是**真**，但属于 vacuous（无实际筛选约束）。验收记录中标为 inactive / vacuous，不把这种判断计入某个实际 M+/M- 模型的命中率。单独的 M01+…M11+、M01−…M11−模型必须提出非空集合，才有模型级成功评分。

新版共同判定器 research/supercompute/v47_set_relations.py 输出所选号码的 belongs / not_belongs 真值、members / nonmembers 列表、集合包含、数学不包含、完全不相交和 M+/M- 成功事件；供22模型、历史两区联合搜索、四区域动态搜索及冻结文件开奖评分共用。冻结文件先做 SHA-256 校验，后续校验完整彩票候选是否满足自身的正反向硬约束，否则 FAIL，不得声称中奖。

抽取号码来自同一个彩种的前后区，且每次实际验证必须匹配期号；同一条冻结预测不可在开奖后修改或通过未来开奖再次选择训练参数。对每期要求记录：全部所选号码、每号码是否开出、M+ 是否集合全部包含、M- 是否全部不属于、前后区组合是否保留真实结果、最终完整票的前区/后区命中及头奖结果。随机基线和 NO_EDGE 保持不变；集合计算正确不等于头奖中奖率改善。
