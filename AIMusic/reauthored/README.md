# AI Music Production System — re-authored staging lineage

This is a new, explicitly re-authored lineage created after the historical `AI_Music_Pro.exe`
candidate was recovered without a reconstructable source/build lineage.

Recovered product purpose:
idea → lyrics → structure → chords → melody → arrangement → vocal → mix → master →
versions → review → revise → final → Evidence/Replay.

This staging candidate implements the parts that can be verified without inventing a cloud provider:
real deterministic local WAV generation, project/evidence storage, repair, advanced analysis,
a four-entry desktop UI (`AI创作｜一键更新｜一键修复｜高级制作`), independent updater
process boundary, and fail-closed status reporting.

It deliberately does **not** claim that a local procedural synthesizer is an external AI model.
External AI model/provider identity, vocal generation, external model licensing, independent
production repository, positive Release N→N+1 updater, formal release re-download Same Hash,
and Final Gate remain NOT VERIFIED/BLOCKED until real evidence exists.
