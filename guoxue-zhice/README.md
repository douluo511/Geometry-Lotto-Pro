# 国学智策系统 v0.1

这不是“20 本书 = 20 句鸡汤”的阅读器，而是一个把传统经典转化为现实判断工具的 Windows 原型。

## 四个入口

- **目标推演**：输入现实目标，先拆事实、利益、约束与风险，再调取多个经典视角。
- **一键更新**：联网读取 GitHub 更新清单，校验 SHA256 和数据结构，暂存后原子替换；失败时保留旧库。
- **一键复盘**：记录目标、行动、结果与教训，形成个人决策审计轨迹。
- **高级分析**：查看经典条目、推演次数、复盘次数、争议文本提示和治理规则。

## 治理原则

1. 原典、后世解释、网络概括分层。
2. 每个经典条目必须有来源说明与适用边界。
3. 《冰鉴》等存在作者归属争议的文本必须显式标注。
4. 《货殖列传》作为《史记》篇章处理；“阳明心学”以《传习录》等文本承载，而不是虚构一本同名原典。
5. 任何现实结论都标记为 `ACTION_HYPOTHESIS`，并强制经过 5 Why 与逆转验证。
6. 《黄帝内经》等仅作为历史思想材料；健康问题不以古籍替代现代医学。

## Windows EXE 验收

GitHub Actions 在 Windows Server 2022 上执行：源码编译、自测、单元测试、真实网络更新、PyInstaller 自包含构建、exact-EXE 自测、GUI 启动 smoke、SHA256 绑定和最终发布闸门。
