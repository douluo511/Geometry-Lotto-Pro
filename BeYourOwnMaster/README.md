# Be Your Own Master — V10 re-authored Windows candidate

This is an explicitly **new implementation lineage** built from recovered V10 business/acceptance requirements. It does **not** claim byte-identical recovery of a historical application source or EXE.

Frozen behavior:

- facts and interpretations stay separate;
- every 5 Why layer is a hypothesis, never causal proof;
- reversal requires a strongest counterexample and a falsifier;
- major decisions pre-register prediction, confidence, maximum acceptable loss and stop line;
- action defaults to the smallest reversible experiment;
- outcomes are attributed to fact / causal model / execution / luck;
- review updates one observable behavior rule;
- health/legal/safety/large-money cases escalate instead of being answered from stories;
- 30/90-day personal effectiveness remains **NOT VERIFIED** until real longitudinal evidence exists.

The public repository contains software logic and acceptance rules, not the user's private V10 document/workbook bytes.

Repository independence, positive production update and real Release N→N+1 remain blocked until the independent repository execution context exists.
