# Geometry Lotto Pro SSQ — Windows exact-EXE validation

This repository builds the SSQ app **natively on GitHub `windows-2022` with Python 3.11 x64 + pinned PyInstaller**. It does not re-pack an old Windows EXE on Linux.

The workflow uploads the EXE artifact **only when every exact-EXE check passes**. Checks include self-test, integrity tamper rejection, offline fail-closed, live official-source update, corrupt-data repair, frozen scientific protocol, three full random-world false-positive attacks, prediction Final Gate, non-freezing audit, Win32 four-button WM_COMMAND routing, and execution from a Chinese path with Python removed from PATH.

Scientific `NO_EDGE / NULL_DAN` is a valid result. The scientific check passes when the frozen protocol executes correctly; it does not require or manufacture a predictive edge.

The authoritative evidence file is `evidence/SSQ/WINDOWS_EXACT_EXE_ACCEPTANCE.json`. The EXE SHA-256 in that report must equal the SHA-256 emitted by each exact-EXE check.
