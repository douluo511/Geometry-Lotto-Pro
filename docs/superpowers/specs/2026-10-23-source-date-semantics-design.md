# Retained source date semantics correction

The original465 DLT recent observation captured two complete Jiangsu pages and
replayed200 legal number/issue rows. Both raw pages label the first column
发布日期, while the shared application parser assigns it to Draw.draw_date.
Row accounting, chronological ordering and weekday agreement do not establish
that a publication date is a draw date. No actual forecast used this material.

This defect was independently reproduced on original unchanged bytes and8
synthetic structural variants. Original manifest SHA256 is
4a6ea7f04f392fc8101d0107ce97f4ef336a8e0b26f89ffbabae574bcefb0405.
Keep originals, old source-only TSA, old archives and their hashes unchanged;
the external quarantine assessment records the new finding without backdating.

## Chosen correction

Select only the research date-semantics helper from independently reviewed
PR464 at0d5ba875900b0efe5fb791078ab57889da39d8b1. It binds every literal legacy
candidate to its actual table/row/column and preceding explicit draw-date,
issue and number headers under a restricted grammar. Unknown/publication
schemas, hidden/inert/escaped contexts and malformed release tokens reject.
Wire the same helper both into the original official replay path and into
recent_observation._worker after HTML decode, before the legacy parser.

A page-wide header search would borrow decoy labels; the independent probe
already demonstrates that bypass. Reinterpreting publication values as draw
dates, reconstructing dates from weekdays or accepting only a convenient tail
would fabricate the required semantics. Those approaches are excluded.

The shared SSQ/DLT application parsers, model core, parameters, fixed NULL,
statistics and scheduler remain unchanged. Existing complete-row, raw/hash,
URL, calendar, size, Windows path and separate-process checks remain. Only
invented positive fixtures acquire an explicit supported draw-date header;
original publication pages do not.

## Failure and identity behavior

Capture continues to save each fully received raw body before parsing. A bad
page1 stops before page2; a bad page2 preserves both bodies. Neither creates a
successful manifest, selected history or observation metadata. No row/date
correction, fallback or skipped-row recovery is permitted.

Changing official_intake.py and recent_observation.py changes parser pins and
future orchestration identity. A pin mismatch on an old manifest is not proof
of semantic rejection: directly run the corrected semantic guard on each
original body as a separate read-only forensic check and verify original
hashes unchanged. Old pinned code can reproduce the mistaken acceptance only
as explicitly quarantined forensic evidence, never as admitted history.

Explicit draw-date labels establish schema interpretation only; source truth,
publication time, independent120-period consensus, target/cutoff and TSA trust
remain unverified. The actual Jiangsu publication-only endpoint remains
blocked until genuine draw-date evidence can be acquired; this correction
does not claim to recover that evidence. No actual output is permitted before
the user's target/cutoff authentication condition.
